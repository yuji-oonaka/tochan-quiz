# 父ちゃんクイズ (Father Quiz)

https://tochan-quiz.vercel.app/

「父ちゃん」が好きな雑学やネタを詰め込んだ、隙間時間にサクッと楽しめるクイズアプリです。
難しすぎず、でも「おっ？」と少し考えさせられる絶妙な難易度を目指しました。

## 🌟 特徴

### 1. 「父ちゃん好み」の厳選問題
歴史、昭和のネタ、ちょっとした教養など、父ちゃん世代がニヤリとするような問題をセレクト。
* **1周目**: セットごとの流れを楽しめる順序通りの出題。
* **2周目以降**: 全問シャッフルモードに突入。毎回違う並び順になるので、飽きずに何度でも遊べます。

### 2. ストレスフリーな「4択形式」
記述式ではないので、答えが喉まで出かかっているのに出てこない…というストレスがありません。
「これだ！」と直感で選べる4択式なので、移動中や寝る前のちょっとした時間でも手軽にプレイでき、絶対に詰むことがありません。

### 3. 目と耳で楽しむ「読み上げ機能」
問題文と解説を音声で読み上げます。
小さい文字を読むのが疲れる時でも、ラジオ感覚でクイズを楽しめます。（ブラウザの制限を考慮し、確実な再生ロジックを実装済み）

### 4. 達成感のある演出
* **10問でひと区切り**: ダラダラ続かず、キリの良いところで終われます。
* **ご褒美画面**: 全問正解しなくても、10問終わるごとに独自の画像とメッセージで労います。

### 5. ユニバーサル・レスポンシブデザイン
* **iPhone SE3 最適化**: 画面の小さなスマホでもボタンが押しやすく、誤操作しないようレイアウトを調整。
* **PC対応**: 大きな画面でも視線移動が少なくて済む、中央寄せデザイン。

---

## 🛠 技術スタック

* **Framework**: Next.js (App Router)
* **State Management**: Zustand + Persist Middleware (進捗の自動保存)
* **Styling**: Tailwind CSS
* **Icons/Images**: Next Image
* **Speech**: Web Speech API (Custom Hook)
* **Sound**: HTML5 Audio (Custom Hook)
